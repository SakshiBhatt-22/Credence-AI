# Credence AI

### AI-Powered Credit Risk Assessment & Loan Underwriting Platform

**Project Status:** Ongoing 🚧

Credence AI is an intelligent fintech platform that leverages machine learning to assess borrower credit risk and streamline the loan underwriting process.

### Features

- Loan application management
- Automated credit risk assessment
- Risk scoring and classification
- Loan officer dashboard
- Underwriting decision management
- Explainable AI for transparent risk assessment

### Tech Stack

- **Frontend:** React, JavaScript, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL, Prisma ORM
- **Machine Learning:** Python, Scikit-learn

### Project Structure

- `client/` – Frontend application
- `server/` – Backend APIs and business logic

### Disclaimer

Credence AI is an educational portfolio project. Its risk assessments are experimental and are not intended for actual lending decisions.
